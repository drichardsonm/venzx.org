# Voz Ciudadana

Create a Civic Technology (CivicTech) web application for citizens to submit and aggregate ideas using AI, ensuring absolute anonymity and security (anti-persecution architecture). The interface should be modern, clean, mobile-first, and highly intuitive. 



Use Supabase/PostgreSQL for the database and Tailwind CSS for the UI. Implement the following 5-screen flow:



### SYSTEM CORE LOGIC & PRIVACY (CRITICAL)

- No emails, names, phone numbers, or IP logging.

- Anonymous identity is based on a "Secret Word/Phrase" (User Hidden ID) created by the user.

- On the backend, this Secret Word must be hashed using SHA-256 before saving to ensure database leaks reveal zero human identities.

- Publicly, users are displayed only as sequential numbers (e.g., User #1, User #2540).



### SCREEN SPECIFICATIONS



#### Screen 1: Idea Generator (Home)

- A prominent central chat-like or search-like text area where users type their proposal.

- Three large action buttons below the text area: 

  1. 🟢 "Quiero" (I want)

  2. 🔵 "Me gusta" (I like)

  3. 🔴 "No me gusta" (I dislike)

- Action: When submitted, process the proposal and trigger a success modal displaying a downloadable "Digital Ticket". The ticket shows their public "User #XXXX" and their "Secret Word". Provide an easy "Copy Secret Word" and "Download Ticket (.txt)" button.



#### Screen 2: Anonymous Profile (Identification)

- Simple form to claim or load an identity using the "Secret Word".

- Once entered, allow the user to fill/update purely demographic data using dropdowns:

  - Gender: Hombre / Mujer / Venezx

  - Age Range: 13-18 / 19-25 / 26-40 / 41-60 / +61

  - Interests: Multiple tags select (Economía, Salud, Servicios, Educación, Tecnología)

  - Location: Cascading dropdowns for Venezuela: Estado -> Municipio -> Parroquia.



#### Screen 3: Idea Explorer (Feed)

- An infinite feed of submitted cards displaying the proposals.

- Each card shows: The text, the public "User #XXXX", the category, and a timestamp.

- Interactivity: Two quick buttons per card: 👍 "Apoyar" (Support) | 👎 "Discrepar" (Disagree).

- Sidebar Filters: Allow filtering the feed by demographic data (e.g., "Show what women aged 26-40 are proposing" or "Filter by Servicios Públicos in Zulia").



#### Screen 4: Heatmaps & AI Insights (Data Viz)

- An interactive map visualization of Venezuela (split by States/Municipios using a clean SVG map or mock geographic layout).

- A natural language search bar at the top (e.g., "What do youth in San Cristóbal need?").

- Display dynamic semantic charts based on selected locations or search queries:

  - Top 3 urgent community priorities (Bar chart).

  - Keyword/Topic cloud generated by AI analysis.

  - The most supported proposal of the week in that region.



#### Screen 5: Voting Center (Governance)

- Tabbed view: 🏛️ National Votes | 📍 Regional & Local Votes.

- Displays active and historical voting polls called by the AI or community milestones.

- Logic: Users must input their Secret Word to unlock voting. The system checks their Screen 2 profile; if their Municipio/Estado matches the poll's restriction, the "Cast Vote" button activates.

- Transparency: Provide a downloadable anonymized CSV link for concluded polls (e.g., "User #105 voted YES", "User #432 voted NO") for public auditability.



### DATABASE SCHEMA (SQL)

Initialize the database with these tables:

1. `usuarios` (id_correlativo SERIAL PK, secreto_hash TEXT UNIQUE, genero, edad_rango, estado, municipio, parroquia, intereses TEXT[], fecha_registro)

2. `propuestas` (id_propuesta SERIAL PK, id_usuario FK, tipo_intencion, contenido TEXT, estado_propuesta DEFAULT 'Revision', fecha_creacion)

3. `apoyos_propuestas` (id_apoyo SERIAL PK, id_usuario FK, id_propuesta FK, voto_tipo, UNIQUE(id_usuario, id_propuesta))

4. `votaciones_convocadas` (id_votacion SERIAL PK, titulo, descripcion TEXT, alcance_geografico, estado_restriccion, municipio_restriccion, fecha_inicio, fecha_fin, activa)

5. `votos_finales` (id_voto SERIAL PK, id_votacion FK, id_usuario FK, opcion_seleccionada, UNIQUE(id_usuario, id_votacion))



Build a fully operational

, beautiful frontend prototype connecting these modules.
